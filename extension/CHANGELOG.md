# Changelog

All notable changes to the mddlmn VS Code extension.

## 0.1.1

- Added marketplace logo
- Rewrote the Details page with usage, features, and architecture
- Enriched the Features page metadata: keywords, categories, repository, license

## 0.1.0

- Initial release.
- Starts the local mddlmn proxy on extension activation and injects `ANTHROPIC_BASE_URL` into Claude Code and integrated terminals.
- Opens the inspector webview with live request capture, section classification, token counts, diff, and timeline.
- Gate, secret redaction, prompt injection, and full section editing of held requests.
